# Data Professional Survey Dashboard using Power BI

## Project Overview

Interactive **Power BI dashboard** created to analyze survey data from data professionals and present insights through interactive visualizations.

The dashboard provides a visual breakdown of survey responses and enables users to explore patterns and trends across the collected data.

## Objectives

- Analyze survey responses from data professionals
- Explore key patterns and trends in the survey data
- Present insights through interactive visualizations
- Build an easy-to-understand business intelligence dashboard

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Modeling

## Dashboard Features

- Interactive KPI cards
- Survey response analysis
- Data professional insights
- Interactive charts and visualizations
- Filters and slicers for dynamic analysis

## Project Highlights

- **Dashboard:** Microsoft Power BI
- **Project Type:** Survey & Business Analytics
- **Data Analysis:** Survey Response Analysis
- **Data Preparation:** Power Query
- **Calculations:** DAX
- **Visualization:** Interactive Power BI Dashboard

## How to Use

1. Download `data_professional_survey_breakdown_dashboard.pbix` from the `PowerBI` folder.
2. Open the file using **Power BI Desktop**.
3. If prompted, review or update the data source.
4. Refresh the data if required.
5. Use the available filters and visualizations to explore the dashboard.
